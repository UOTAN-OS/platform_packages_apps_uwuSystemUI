# uwuSystemUI

## 原 uwuAOSP 项目说明

`uwuSystemUI` 是 uwuAOSP 的 SystemUI 插件集，包含 MomentArc、状态栏歌词、短信验证码和剪贴板智能建议等功能。

源项目：[uwuAOSP/platform_packages_apps_uwuSystemUI](https://github.com/uwuAOSP/platform_packages_apps_uwuSystemUI)

## UotanOS 集成

- 保留 `uwuSystemUI`、`org.uwuaosp.systemui`、uwu 广播和设置组件标识。
- UotanOS 仅调整用户可见的平台品牌，组件技术标识保持不变。
